# 從喜歡的設計開始規劃自己的網站
先選用途與首頁的閱讀動線，再決定品牌色、頁面與導航。最後取得一份可以交給 AI 接續開發的網站規格。
這裡是規劃工具，不會直接修改正式網站、建立新 Repository 或發布。

## 品牌視覺
先選一組配色起點，再自由調整五色盤。這些是配色預設，不會改變你在步驟 01 選的整頁 Layout。

### 不知道怎麼配色？先到這三個工具看看 
找到喜歡的色彩後，把 HEX 色碼帶回上方色盤，再確認背景、文字和按鈕是否清楚易讀。 
  [https://coolors.co/]Coolors ↗快速產生五色組合，可鎖定喜歡的顏色再重新搭配。  [https://www.happyhues.co/]Happy Hues ↗不只看色票，還能看背景、標題、按鈕在真實版面中的搭配。  [https://color.adobe.com/]Adobe Color ↗用色輪、照片建立配色，並檢查文字與背景對比。  
外部工具僅供配色靈感參考，不會自動讀取或套用配色；仍請檢查實際文字與按鈕對比。

## 選擇組合樣板（選填）
組合樣板不是單顆按鈕，而是完成一件事的整段內容。例如「精選文章／作品」會把標題、說明、代表內容與下一步串起來，幫第一次來的讀者快速找到值得看的東西。 [/section-patterns/#featured-work]看「精選作品／文章」的整段示範 ↗ 
 精選內容展示（文章／作品／專題） 
適合首頁：先介紹這一區，再放 2–3 篇精選文章、作品或專題，最後提供「查看更多」入口。不是填數字或憑空聲稱成果。 
這一段包含：區段前言 → 精選項目列表 → 清楚的下一步  [/section-patterns/#featured-work]查看完整區段與所需資料 ↗ 
放在哪頁放置位置 
 專業信任與服務入口 
讓訪客先了解合作範圍、服務適合度與實際聯絡方式，而非只看到預約按鈕。 
這一段包含：專業服務定位 → 服務適合度 → 可核實信任資訊 → 低壓下一步  [/section-patterns/#trust-service-path]查看完整區段與所需資料 ↗

### 全站頁腳樣式
頁腳會自動放在整站所有頁面的底部。只要選一種，不用選擇放哪頁；也可以選「不另外設定」，之後再調整。 
 選擇頁腳  暫不選擇 簡約品牌頁腳精簡品牌介紹、少量導覽與底部版權。內容型多欄頁腳文章主題、作者資訊、社群、RSS 與隱私權入口。專業服務多欄頁腳服務、關於、聯絡資訊以不同選單群組整理，底部呈現法律資訊。
