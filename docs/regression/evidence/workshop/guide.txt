# 開始建置自己的網站
選版型、上傳檔案、請 AI 建站、預覽並發布。

01
## 選擇網站設計
到規劃器選網站類型、Layout、品牌色、頁面與選單，下載 Site Brief JSON。 
 [/starter/]開啟網站規劃器 →  
你要做的事開啟網站規劃器，完成選擇點下載，確認電腦裡有一份 JSON 檔案      
02
## 把檔案交給 AI
上傳規劃檔與建站資料包，傳送提示詞。  
### 下載給 AI 的建站資料包
完整離線建站資料包（包含網站生成器、版型、元件、設計 Skills 與相關原始碼），下載後與 Site Brief JSON 一起交給 AI。下載 AI 建站資料包 ZIP ↓
如果 AI 無法接收 ZIP，請改用能上傳完整資料夾或多檔專案的工具，解壓後保留 .ai/、src/、scripts/ 等原始目錄結構；不能只傳 README 或幾份 Markdown。若工具無法保留檔案路徑，請先換成支援 ZIP／專案檔案的 AI 工作模式，再開始建站。 
你要做的事上傳剛下載的 Site Brief JSON點下方按鈕下載 AI 建站資料包 ZIP，一起上傳貼上「開始建站」提示詞 
開始建站複製提示詞
我已上傳網站規劃檔與建站資料包。請依照資料包幫我建立網站，一次只問我一個需要確認的問題。完成後提供預覽網址，等我同意再正式發布。     
03
## AI 製作網站
AI 建立網站後，打開預覽連結查看。   
你要做的事請 AI 告訴你下一步要確認什麼收到網站預覽連結後，實際打開看首頁、About 與文章／服務頁      
04
## 讓網站可以預覽
沿用前置準備選定的發布方式，取得網站預覽網址。   
你要做的事依 AI 提示在託管平台完成必要的連接與授權打開 AI 提供的網址，看圖文與連結是否正常  
Cloudflare Pages
B 路線：保留私人原始碼、方便預覽。 [https://dash.cloudflare.com/]打開 Cloudflare ↗
GitHub Pages
A 路線：簡單免費，原始碼公開。 [https://github.com/]打開 GitHub ↗
 [/guide/prepare/#hosting]查看 A／B 發布方式設定步驟 →
請 AI 引導連接網站託管複製提示詞
我想把這個網站放上網路，使用【Cloudflare Pages／GitHub Pages】。請依我眼前的網站畫面，一次教我按一個步驟。碰到畫面不一樣就請我截圖，不要猜測按鈕位置。程式設定由你處理；每一步請告訴我完成後應看到什麼。先取得可打開的測試網址，不要擅自發布正式版本。    
05
## 提出修改意見
截圖告訴 AI 需要修改的地方。   
你要做的事用手機和電腦看實際頁面截圖圈出問題、說明希望改成什麼重開更新後的預覽連結確認   
請 AI 幫我修正畫面複製提示詞
這是我的網站預覽連結：【貼網址】。這是我想修改的地方：【用自己的話描述，也可以附截圖】。請只修改這次提到的問題，保留原本選擇的設計風格。修好後給我新的預覽連結，並用白話告訴我改了什麼。先不要合併或發布。   
06
## 確認後正式發布
確認內容、圖片與連結後再發布。   
你要做的事檢查網站資訊、主要按鈕、文章／服務與手機畫面確認沒有不願公開的資料滿意後再明確同意發布    
請 AI 進行上線前檢查複製提示詞
我正在確認網站能不能正式公開。請替我檢查頁面、圖片、連結、搜尋、手機畫面與不應公開的資料。請用「正常／有問題／需要我親自看」三類白話回報，並提供預覽網址。我還沒有同意合併或發布，請先等我確認。  
07
## 上線後更新網站
更新內容時，先預覽再發布。   
你要做的事收藏自己的正式網址與 GitHub 倉庫網址下次修改時先請 AI 提供預覽，不直接覆蓋正式站     
請 AI 幫我日後更新複製提示詞
我想修改自己已上線的網站：【說明想改什麼】。請先製作一份不影響目前正式網站的預覽版本，提供網址讓我查看。確認沒問題再問我是否同意發布。  
## 看不懂畫面，怎麼辦？
把你現在看到的網頁截圖傳給 AI，告訴它「請照這張畫面，一次只教我下一個要按的按鈕。」
截圖前遮住密碼、驗證碼與私人資料。 
## GitHub 常用頁面
Pull requests 查看修改，Actions 查看建置。
請 AI 提供你自己網站的 GitHub Repository 網址，進入該 Repo 的 Pull requests 和 Actions。不需要進入老師的研究 Repo。
請 AI 提供你的網站 PR 與 Actions 連結。
